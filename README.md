# NodeThemes SEO AI

**Free AI SEO plugin for WordPress and WooCommerce.**

NodeThemes SEO AI is a free AI SEO plugin for WordPress and WooCommerce. It helps you rank in Google and get cited by AI answer engines such as ChatGPT, Gemini, Claude and Perplexity, powered by your own OpenAI, Claude or Gemini API key.

- Website: [NodeThemes SEO AI on nodethemes.com](https://nodethemes.com/product/nodethemes-seo-ai-pro-ai-seo-plugin-for-wordpress-woocommerce/)
- All free plugins: [Free WordPress plugins from NodeThemes](https://nodethemes.com/free-plugins/)

## Features (free version)

- Optimise any page, post or product with AI: keyphrase, SEO title, meta description, FAQ and key takeaways
- SEO and AI-readiness checks with a score on every page
- AI writer for articles and product pages (up to about 700 words)
- Meta tags, canonical, Open Graph, Schema (JSON-LD), XML sitemap and llms.txt
- Redirects, 404 monitor and automatic redirect when a slug changes
- Link Map, internal link suggestions (3 per page) and AI-crawler visit log
- Import from Yoast, Rank Math and AIOSEO
- AI-visibility tracker for 3 questions

## Installation

1. Download the latest version from [nodethemes.com/free-plugins](https://nodethemes.com/free-plugins/) or from the **Releases** of this repository.
2. In WordPress go to **Plugins → Add New Plugin → Upload Plugin**, choose the zip and click **Install Now**, then **Activate**.
3. New versions then appear in **Dashboard → Updates** like any other plugin.

Requirements: see the plugin header and `readme.txt`.
